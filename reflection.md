# Tinker: Rank & Explain -- Reflection

## Part 4: Bias in my weighting

**Filter bubble sentence:**
Because noise and distance are each worth 2 points while seats are worth only 1, spots that are loud or far away can never reach the top 3 for a quiet, nearby profile, so over time a user only ever sees the same few quiet, close places and never discovers the rest of campus.

**Who might be underserved:**
A student organizing a group project or study group, who needs a big room with lots of seats. Seats are worth only 1 point, so a spot with 25 seats ranks the same as one with 4. Student Union Tables has the most seats (25) and is also the closest (0.1 mi), but it's loud, so it scores 2.0 and never shows up.
